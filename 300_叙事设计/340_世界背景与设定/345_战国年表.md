# 战国年表

## 凡例（纪年基准与体例）

```
基准: 本表主纪年以《史记·六国年表》为基准。
      《六国年表》上起周元王元年(前476年)，下讫秦二世三年(前207年)，
      首尾约270年，为司马迁"因《秦记》而作。

体例: 六国年表实列周、秦、魏、韩、赵、楚、燕、齐八栏，
      "名六国、实七国"，以秦为主、以周为正统。
      本表沿用这一视角 → 秦系记事最详，他国记事相对简略。

异说: 与《竹书纪年》、清华简《系年》、帛书《战国纵横家书》等
      其他记载不同的纪年，以【注】标出异说。
      游戏文案如涉及具体年份，优先采用本表正文所标年代。

范围: 聚焦游戏相关的 前476 — 前202年。
      前453年三家灭智氏 = 战国时代实质开端
      前221年秦统一 = 战国时代结束
      前206年秦亡/前202年汉兴 = 余波
```

## 前476-前350: 战国初期——格局形成

```
前476年  六国年表起年(周元王元年) → 本表追叙的起点

前473年  越王勾践灭吴 → 夫差自杀 → 勾践北上称霸(吴越记事，春秋尾声)

前453年  晋阳之战 → 智伯水灌晋阳 → 赵襄子联韩、魏反灭智氏
         "三家分晋"格局奠定 → 战国时代的实质开端

前445年  魏文侯即位 → 重用李悝/吴起/西门豹 → 魏国率先变法称强

前409年  魏伐秦取河西地 → 吴起为西河守(秦失河西，秦魏结怨之始)
前408年  乐羊率魏军围中山 → 前406年灭之【注】中山约前380年复国

前403年  周威烈王正式册命韩/赵/魏为诸侯
         《资治通鉴》记事起于此年 → "礼崩乐坏"的象征时刻

前397年  聂政刺杀韩相侠累(《刺客列传》，六国年表有载)

前391年  田和迁齐康公于海上 → 田氏代齐完成实质一步
         三晋联军伐楚 → 大梁/榆关之战 → 楚求援于秦

前386年  周安王册命田和为齐侯 → 田氏代齐正式完成

前385年  吴起离魏奔楚 → 楚悼王任为令尹主持变法(一说前387年)
前381年  楚悼王卒 → 旧贵族射杀吴起 → 楚国变法中途夭折
         新王追究射中王尸者 → 灭七十余家

前379年  齐康公卒，姜齐绝祀 → 田氏彻底取代姜氏

前376年  三家废晋静公 → 晋绝祀【注】一说前369年

前375年  韩灭郑 → 韩迁都新郑

前367年  周室分裂为西周/东周两个小国

前364年  石门之战 → 秦献公斩魏军六万 → 秦对魏首次大胜，周显王致贺
前362年  少梁之战 → 秦俘魏相公叔痤 → 秦献公卒

前361年  秦孝公即位 → 发布"求贤令" → 商鞅入秦
         魏惠王迁都大梁【注】竹书纪年九年说前361年/六年说前364年

前357年  邹忌讽齐王纳谏 → 齐威王励精图治【注】田齐纪年诸书出入较大
前356年  商鞅第一次变法(徙木立信/废井田/军功爵/连坐)
前355年  申不害相韩昭侯 → 韩国"术治"变法
         齐魏论宝 → 威王答"以人才为宝"

前354年  魏围邯郸(庞涓伐赵)
前353年  孙膑围魏救赵 → 桂陵之战 → 魏军大败
前351年  魏归还邯郸 → 邯郸之难结束

前350年  商鞅第二次变法 → 秦迁都咸阳
```

## 附: 史料依据与纪年争议

### 基准史料

```
《史记·六国年表》
  司马迁"因《秦记》"而作，上起周元王元年(前476年)，下讫秦二世三年(前207年)。
  表列周、秦、魏、韩、赵、楚、燕、齐八栏，"名六国、实七国"。
  以秦为主、以周为正统 → 秦系纪事最详，六国纪事多有缺略。
  本表所有主纪年皆以此为准。
```

### 当时其他国家的记载(参照)

| 史料 | 性质 | 对年表的价值 |
|------|------|-------------|
| 《竹书纪年》 | 魏国国史(汲冢竹书) | 订正《史记》战国纪年最重要的参照，尤以魏、齐纪年为关键 |
| 《秦记》 | 秦国官方编年(已佚) | 六国年表的主要底本 |
| 《战国策》 | 纵横家说辞汇编 | 事件细节与外交辞令的素材库 |
| 马王堆帛书《战国纵横家书》 | 苏秦书信(前308-前284) | 重塑苏秦年代与活动 |
| 清华简《系年》 | 战国楚系史书 | 春秋末至战国初晋、楚、越记事 |
| 睡虎地秦简《编年记》 | 秦下级官吏编年 | 印证秦昭王至始皇的纪年 |

### 主要纪年争议与处理

```
1. 三家分晋/晋绝祀
   六国年表系于前376年；《竹书纪年》推算一说前369年。本表从《史记》。

2. 马陵之战
   《六国年表》系于前341年；《竹书纪年》系于前343-前342年(跨年之战)，
   钱穆、杨宽等学者多从后者。本表正文从前341年，以【注】存异。

3. 魏惠王迁都大梁
   《竹书纪年》九年说前361年、六年说前364年(同书引文之异)。本表取前361年。

4. 苏秦年代
   传统说法: 前334年合纵六国、前317年(或前321/前319年)被杀(史记/通鉴)。
   帛书《战国纵横家书》: 苏秦活动于前308-前284年，为燕昭王间谍，
   前284年因反间败露被齐车裂；合纵首倡者为公孙衍。学界主流倾向帛书说。
   本表保留传统叙事(玩家认知度高)，并在相应条目加【注】。

5. 楚灭越
   前306年(楚怀王，杨宽说，主流) / 前333年(楚威王，史记越世家/通鉴)。
   本表取前306年。

6. 田齐世系纪年
   《六国年表》与《竹书纪年》相差可达十余年(如齐威王元年)。
   本表对齐国事件年代从《六国年表》，个别通行折衷加【注】。

7. 周元王元年
   前476年(史记) / 前475年(据《左传》推算)。本表从《史记》。

处理原则:
  主线年代以《六国年表》为准 → 保证游戏时间轴自洽
  争议处加【注】 → 供考据向玩家/周边内容(设定集)展开
  文案避免精确到"哪一年"的争议事件 → 用"威王时""惠王晚年"等模糊表述
```

## 游戏中的时间标记

```
重要: 游戏时间是"流动的"——
      玩家角色的一生约60-80年
      继承系统可以让玩家跨越整个战国时代

玩家可能经历的历史时刻(取决于出生时间):
  早生(前360年左右出生):
    见证商鞅变法 → 马陵之战 → 合纵连横 → 长平之战
    
  中生(前300年左右出生):
    见证长平之战 → 秦灭六国 → 统一天下
    
  晚生(前260年左右出生):
    出生在长平之战后 → 成长在秦统一过程中
    
  跨时代(通过继承):
    第一代: 参与长平之战
    第二代: 参与秦灭六国
    第三代: 见证秦的速亡

事件素材(本次扩充后):
  小国灭亡链(郑/宋/中山/鲁/周室) → 区域任务与压迫感叙事
  刺客事件(聂政/荆轲/博浪沙) → 暗杀玩法的事件原型
  变法节点(商鞅/申不害/吴起) → 内政系统的时间锚点
  纪年争议【注】 → 设定集/考据彩蛋的展开空间
```
