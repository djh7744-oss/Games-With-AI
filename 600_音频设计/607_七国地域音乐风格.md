# 七国地域音乐风格

## 一、概述

本文定义七国（秦/楚/齐/赵/魏/燕/韩）各自的背景音乐风格，目标与 [508_旗帜与徽章规范](../500_美术规范/508_旗帜与徽章规范.md) 对齐：

**玩家不看画面、不看旗帜，仅凭音乐即可辨认身处何国。**

## 二、设计依据：季札观乐

《左传·襄公二十九年》"季札观乐"是先秦最权威的音乐批评——吴公子季札在鲁国逐一品评各国乐风，为七国音乐风格提供了直接的典籍依据：

| 季札评语 | 对应 | 乐风关键词 |
|---------|------|-----------|
| 秦风："此之谓**夏声**，夫能夏则大，大之至也" | 秦 | 宏大 |
| 齐风："**泱泱乎，大风也哉**！表东海者" | 齐 | 开阔 |
| 魏风："**沨沨乎！大而婉**，险而易行" | 魏 | 中正 |
| 唐风（晋地）："**思深哉**……何忧之远也" | 赵（三晋） | 深沉 |
| 郑风："**其细已甚**，民弗堪也" | 韩（新郑为郑故都） | 细靡 |
| 燕地无国风，取《战国策》荆轲刺秦："高渐离**击筑**……为**变徵之声**" | 燕 | 苍凉 |
| 楚地无国风，取《楚辞·九歌》祀神乐舞 | 楚 | 巫风 |

## 三、五声调式与五方对应

五音配五方，七国按地理方位定调：

```
            羽 (北·燕) 苍凉萧瑟
              │
角 (东·齐) ── 宫 (中·魏) ── 商 (西·秦) 肃杀
              │
            徵 (南·楚) 热烈巫风

赵（东北偏胡）：角调偏变徵（慷慨悲歌）
韩（中原郑地）：商调偏宫（精巧细密）
```

## 五、各国设计要点

### 5.1 秦 · 商调战鼓

低频战鼓为骨、编钟为魂，节奏如军阵行进。军功爵制的纪律感——音乐要"整齐得可怕"。

- 参考路线：《大秦帝国》配乐
- 关键音色：大鼓低音群（8-16面齐奏）、青铜号角、石磬强拍
- 情绪曲线：压抑积蓄→骤然爆发（对应秦军"不动如山，动如雷霆"）

### 5.2 楚 · 巫乐

楚辞《九歌》是祀神歌舞，音乐要有"人神对话"的迷离感。

- 关键音色：编钟下滑音、瑟的滑抹、女声无词吟哦（香草美人的浪漫）
- 参考：古琴曲《楚歌》、《轩辕剑》楚地场景
- 情绪曲线：悠远迷离→祭祀高潮的狂放

### 5.3 齐 · 韶乐

齐的招牌是"三月不知肉味"的韶乐 + 商业繁华。音乐要开阔从容。

- 关键音色：竽笙和鸣（滥竽充数典故出齐地）、箫、编磬
- 场景分层：街市段加算盘声/叫卖声采样；学宫段转为书简翻动般的雅致
- 情绪曲线：雍容、富足、不疾不徐

### 5.4 赵 · 胡笳悲歌

赵武灵王胡服骑射，乐风兼有胡人的苍凉与中原的深沉。韩愈"燕赵多慷慨悲歌之士"为情绪基调。

- 关键音色：胡笳、埙、马上鼓；骑兵冲锋段用马蹄声部
- 情绪曲线：苍凉辽阔→慷慨激昂（冲锋）→悲壮回落

### 5.5 魏 · 中原雅乐

季札说魏风"大而婉"——宏大但不尖锐，婉转而不柔弱，正是魏国"人才济济却四面受敌"的中庸处境。

- 关键音色：编钟+琴瑟正统配置，旋律线条长而稳
- 情绪曲线：端方持重，暗含隐忧

### 5.6 燕 · 击筑

高渐离的筑是燕乐之魂——苍凉、孤绝。羽调本身属悲调。

- 关键音色：筑的孤点敲击、埙、风声采样（北地苦寒）
- 荆轲易水送别是这段音乐的最高潮
- 情绪曲线：孤绝→悲壮（易水变徵之声）

### 5.7 韩 · 机巧细密

季札评郑风"其细已甚"——精巧到极致。韩国劲弩冶铁立国，用弩机扣弦、锻铁锤击做打击乐音色。

- 关键音色：筝的快速指法、弩机金属声、密集节奏型
- 情绪曲线：精密、紧张、像一件精工器械

## 六、战场辨识度：音乐母题

七国音乐在战场上需要和旗帜一样可瞬间辨认——每国一个"音乐母题"（记忆点）：

| 国 | 音乐母题（记忆点） |
|----|-------------------|
| 秦 | 三声战鼓 + 一声号角（"赳赳"节奏型） |
| 楚 | 编钟下滑音 + 女声吟哦 |
| 齐 | 竽笙和弦长音（开阔五度） |
| 赵 | 胡笳上滑音（马嘶感） |
| 魏 | 编钟正拍齐奏（队列感） |
| 燕 | 筑的孤点敲击（风声底） |
| 韩 | 弩机连发节奏（密集十六分） |

## 七、实现建议

### 7.1 与 604_音乐系统的 Layer 架构衔接

604 定义的"七国主题音乐自适应 Layer"架构中，本文件为 Layer 的内容层提供素材：

```
基础层（环境音色）: 各国底色音色（如燕=风声+筑、韩=锻铁声）
  ↓ 叠加
情绪层（动态强度）: 战斗强度/昼夜/天气 → Layer 切换
  ↓ 叠加
母题层（辨识标志）: 六、所述音乐母题 → 切换国家时主题动机变换
```

### 7.2 制作优先级（对应 MVP 边界）

MVP 阶段（Phase 1）不做任何背景音乐。进入 Phase 2+ 后按以下优先级制作：

1. 战场音乐母题（辨识度收益最高）
2. 城池/街市环境音乐（秦、齐、韩优先——MVP 首城与初期活动区域）
3. 探索音乐（按地图开放顺序）
4. 特殊场景音乐（易水送别、齐唱《无衣》等叙事高光）

### 7.3 音源建议

- 编钟/编磬/瑟/竽/篪/筑：实录优先，退而求其次用高品质采样库
- 胡笳/埙/号角：可实录，演奏难度低
- 弩机/锻铁/算盘/叫卖声：拟音 + 采样
