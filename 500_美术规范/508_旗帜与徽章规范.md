# 旗帜与徽章规范 — 七国战旗

## 一、概述

本文定义七国（秦/楚/齐/赵/魏/燕/韩）的战旗与族语设计规范，用于：

- 战场旗帜、军团旗帜、城池旗帜
- UI 图标（势力选择、外交界面、主菜单）
- 过场动画、CG 中的势力标识

设计要求对标《权力的游戏》家族纹章体系：**每一面旗子必须能让玩家在战场上瞬间辨认出势力**。

## 二、七国战旗总表

| 国 | 族语（八字） | 战旗 | 出处 |
|----|-------------|------|------|
| 秦 | 岂曰无衣，与子同袍 | 玄黑底 · 金色虎符纹 | 《诗经·秦风·无衣》 |
| 楚 | 楚虽三户，亡秦必楚 | 朱红底 · 凤凰纹 | 楚南公语，见《史记·项羽本纪》 |
| 齐 | 上兵伐谋，其次伐交 | 青底 · 金色刀币海浪纹 | 《孙子·谋攻》孙武语（孙武齐人） |
| 赵 | 胡服骑射，以教百姓 | 赭红底 · 奔马纹 | 《战国策·赵策》赵武灵王语 |
| 魏 | 内修文德，外治武备 | 铜黄底 · 重甲武士执戟纹 | 《吴子·图国》吴起语 |
| 燕 | 卑身厚币，以招贤者 | 素白底 · 玄色飞燕纹 | 《战国策·燕策》燕昭王黄金台招贤 |
| 韩 | 强弓劲弩，皆自韩出 | 铁灰底 · 强弩纹 | 《战国策·韩策》苏秦语 |

## 三、设计原则

### 3.1 配色区分度

七国七色不重样，楚朱红偏火、赵赭红偏土，战场可一眼分辨：

| 国 | 底色 | 色相定位 |
|----|------|---------|
| 秦 | 玄黑 | 水德尚黑（北方肃杀） |
| 楚 | 朱红 | 祝融后裔尚赤（南方之火） |
| 齐 | 青 | 东方属木尚青（海岱之气） |
| 赵 | 赭红 | 胡服骑射之赭（土红） |
| 魏 | 铜黄 | 青铜甲胄之色 |
| 燕 | 素白 | 苦寒雪原·白衣送行 |
| 韩 | 铁灰 | 宜阳冶铁之色 |

### 3.2 图腾符号

每个图腾对应各国最核心的军事/文化符号：

| 国 | 图腾 | 含义 |
|----|------|------|
| 秦 | 虎符 | 军功爵制、调兵之权、虎狼之师 |
| 楚 | 凤凰 | 楚文化核心图腾、火神祝融后裔 |
| 齐 | 刀币 | 商业立国、海盐之利 |
| 赵 | 奔马 | 胡服骑射、天下第一骑兵 |
| 魏 | 重甲执戟 | 魏武卒、青铜重甲步兵 |
| 燕 | 飞燕 | 国名即燕、玄鸟崇拜 |
| 韩 | 强弩 | 宜阳冶铁、天下劲弩 |

### 3.3 族语规范

- 一律为**八字**，两段四言（燕为七言带兮，仍计八字）
- 必须出自**先秦典籍或先秦人物之语**，不自行造词
- 用于：旗帜卷轴题字、势力选择界面、外交/宣战界面、胜利结算画面

## 五、使用规范

### 5.1 应用场景

| 场景 | 规格建议 |
|------|---------|
| 战场军团旗帜 | 3m 高旗杆 + 双面旗帜，LOD 远距离仍需可辨色块 |
| 城池悬挂旗 | 静态旗帜 + 顶点动画，城头每隔 20m 一面 |
| UI 势力图标 | 盾形徽章，单色描边版 + 彩色版各一套 |
| 加载/过场画面 | 旗帜特写 + 族语卷轴字幕 |

### 5.2 资产命名（UE5）

```
/Content/Art/Flags/
  T_Flag_Base_Qin.uasset      # 秦旗底纹
  T_Flag_Emblem_Qin.uasset    # 秦旗虎符纹
  SM_Flag_Field.uasset        # 旗帜通用网格
  MI_Flag_Qin.uasset          # 秦旗材质实例
  UI_Icon_Banner_Qin.uasset   # UI 盾形图标
```

### 5.3 族语文字规范

- 游戏内展示统一使用**篆书/小篆**字体
- 竖排书写：先右后左，八字分两行
- 本地化时保留中文原句，外文版用译文标注出处
