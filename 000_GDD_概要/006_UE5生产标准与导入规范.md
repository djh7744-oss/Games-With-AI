# UE5生产标准与导入规范

## 总则

> 所有设计文档中的数值定义必须可以直接导出为UE5 DataTable可导入的CSV格式。C++代码中的Struct定义必须与CSV列一一对应。策划在Excel中修改数值→导出CSV→UE5自动重导入→无需程序介入。

## 一、命名规范 (UE5兼容)

### 资产路径映射

```
设计文档ID  →  UE5资产路径
─────────────────────────────────────
100_系统设计/110_战斗系统  →  /Content/Blueprints/Combat/
100_系统设计/120_角色系统  →  /Content/Blueprints/Character/
200_数据表/210_兵种/        →  /Content/DataTables/Units/
200_数据表/220_武器/        →  /Content/DataTables/Weapons/
200_数据表/225_角色/        →  /Content/DataTables/Character/
200_数据表/245_将领/        →  /Content/DataTables/Generals/
200_数据表/280_任务/        →  /Content/DataTables/Quests/
```

### 命名前缀规范

| 前缀 | 含义 | UE5类型 | 示例 |
|------|------|--------|------|
| DT_ | DataTable | UDataTable | DT_UnitStats_Qin |
| DA_ | DataAsset | UPrimaryDataAsset | DA_NationConfig_Qin |
| BP_ | Blueprint | UBlueprint | BP_CombatController |
| SK_ | SkeletalMesh | USkeletalMesh | SK_Qin_Soldier_Heavy |
| SM_ | StaticMesh | UStaticMesh | SM_Building_Palace |
| M_ | Material | UMaterial | M_Weapon_Iron |
| MI_ | MaterialInstance | UMaterialInstance | MI_Weapon_Bronze_Sword |
| T_ | Texture | UTexture2D | T_Bronze_Armor_BC |
| AN_ | Animation | UAnimSequence | AN_Horse_Gallop |
| ABP_ | AnimBlueprint | UAnimBlueprint | ABP_Player_Combat |
| WBP_ | WidgetBlueprint | UUserWidget | WBP_CharacterPanel |
| GA_ | GameplayAbility | UGameplayAbility | GA_FourDirectionAttack |
| GE_ | GameplayEffect | UGameplayEffect | GE_BleedDamage |

### DataTable行命名规范

```
格式: [国家]_[类型]_[Tier]_[变体]
示例: 
  Qin_HeavyInfantry_T3_Elite    → 秦国重步兵T3精英
  Chu_Warship_T4_Flagship       → 楚国战舰T4旗舰
  Zhao_Cavalry_T2_Scout         → 赵国骑兵T2侦察
```

```cpp
// 文件: Source/SevenKingdoms/Combat/UnitData.h
#pragma once
#include "Engine/DataTable.h"
#include "UnitTypes.generated.h"

    HeavyCavalry   UMETA(DisplayName = "重骑兵"),
    Archer         UMETA(DisplayName = "弓兵"),
    Crossbow       UMETA(DisplayName = "弩兵"),
    Chariot        UMETA(DisplayName = "战车"),
    Siege          UMETA(DisplayName = "攻城器械"),
    Naval          UMETA(DisplayName = "水军"),
};

UENUM(BlueprintType)
enum class ENation : uint8
{
    Qin  UMETA(DisplayName = "秦"),
    Chu  UMETA(DisplayName = "楚"),
    Qi   UMETA(DisplayName = "齐"),
    Zhao UMETA(DisplayName = "赵"),
    Yan  UMETA(DisplayName = "燕"),
    Wei  UMETA(DisplayName = "魏"),
    Han  UMETA(DisplayName = "韩"),
    Zhou UMETA(DisplayName = "周"),
};

USTRUCT(BlueprintType)
struct FUnitData : public FTableRowBase
{
    GENERATED_BODY()
    
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="基础")
    FName UnitID;                    // 唯一ID, 例: Qin_HeavyInfantry_T3
    
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="基础")

    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="基础")
    EUnitType Type;                 // 兵种类型
    
    // 战斗属性
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="战斗")
    int32 Attack = 10;              // 攻击力 (10-200)
    
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="战斗")
    int32 Defense = 5;              // 防御力 (5-150)
    
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="战斗")
    int32 Health = 50;              // 生命值 (50-500)
    
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="战斗")
    int32 Morale = 50;              // 基础士气 (0-100)
    
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="战斗")
    int32 MoveSpeed = 100;          // 移速 基准100
    
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="战斗")
    int32 Range = 0;                // 射程 0=近战
    
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="战斗")
    int32 Ammo = 0;                 // 弹药 0=无限(近战)
    
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="战斗")
    float ArmorPenetration = 0.0f;  // 破甲率 (0.0-1.0)
    
    // 经济属性
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="经济")
    int32 RecruitmentCost = 100;    // 招募费(金)
    
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="经济")
    int32 UpkeepPerMonth = 10;     // 月维护费(金)
    
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="经济")
    int32 TrainingDays = 5;        // 训练天数
    
    // 特殊能力
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="特殊")
    FName SpecialAbility;          // 特殊能力ID (对应GA_)
    
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="特殊")
    FName RequiredTech;            // 所需科技ID
    
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category="特殊")
    FText Description;             // 描述文本(本地化)
};
```

## 三、CSV导入规范

### 3.1 CSV格式要求

```
1. 第一行: 列标题(英文, 与C++ Struct属性名完全一致)
2. 第二行起: 数据
3. 编码: UTF-8 (无BOM)
4. 分隔符: 逗号(,)
5. RowName: 第一列必须是行名(作为FTableRowBase的RowName)
6. 引用: 包含逗号的字段用双引号包裹
7. 枚举: 可直接写枚举短名(如 HeavyInfantry), UE通过DisplayName/枚举名解析; 完整路径(如 EUnitType::HeavyInfantry)亦可接受。CSV中统一使用短名(与现有DT_*.csv一致)
8. 数组: TArray字段使用格式: (Item1,Item2,Item3) 
9. 注释: 不支持CSV内注释, 额外信息放在Description列
```


### 3.3 UE5导入步骤

```
1. 将CSV文件放入: /Content/DataTables/Import/
2. UE5 Editor自动检测→弹出Import Dialog
3. 选择对应的Struct类型(如: FUnitData)
4. 确认RowName列映射
5. 导入→生成DT_UnitStats.uasset
6. 原始CSV保留在Source/目录(版本控制)
```
