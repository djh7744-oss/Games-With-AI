# 诸子百家门派任务

## 设计目标

> 十家学派各有10-15个专属任务，从入门到宗师，完整覆盖一条"思想者"的人生轨迹。每个任务不是"去A杀B回来领赏"——而是体现该学派核心价值观的叙事体验。儒家让你教化百姓，法家让你铁面执法，墨家让你守城救民，道家让你静坐悟道。

## 学派任务共同规则

- **可多修**: 可同时加入多个学派(不少历史学者兼修多家)
- **统一五级**: 弟子(入门)→门徒(Lv2)→学者(Lv3)→宗师(Lv4)→Lv5终极称号(儒家宗师/法家宗师/墨家巨子/道家真人等, 以学派任务配置表.csv为准)
- **每级包含**: 1个升级任务 + 2-3个可选支线任务 = 每学派10-15个任务
- **互斥学派**: 法vs儒、墨vs名，冲突学派高级任务额外难度+30%
- **退出惩罚**: 退出后该学派声望归零，且被视作"叛徒"(好感-50)

## 一、儒家 —— 仁义之道 (12个任务)

### 学派特色
```
核心价值: 仁义礼智信，以德治国
代表人物: 孔子/孟子/荀子
圣地: 鲁国曲阜孔庙 / 齐国稷下学宫
色调: 素白+朱红
对立: 法家
```

### 任务链

**1. 入门「问道曲阜」** (Lv1 弟子)
```
触发: 智略≥30 + 仁义≥20 + 前往曲阜孔庙
NPC: 孔庙老儒
场景: 你站在孔庙门前。老儒打量着你。

对话:
  老儒: "你为何而来?"
  选项A: "为求学问。" → 老儒缓缓点头 → 试炼: 抄写《诗》三篇(3天)
  选项B: "为救天下。" → 老儒眼睛亮了 → 试炼: 去附近村庄调解邻里纠纷
  选项C: "为出人头地。" → 老儒沉默 → "那你来错地方了。但既然来了——"
        → 试炼更严苛: 抄《诗》+《书》+《礼》共九篇(7天)

完成: 成为儒家"弟子"
奖励: 仁义+5, 智略+3, 获得《论语》竹简(可阅读提升智略)
```

**2. 支线「有教无类」** (Lv1)
```
触发: 儒家弟子+在任意城池
NPC: 三个贫民子弟
场景: 三个孩子在学堂外偷听讲课。教书先生赶他们走:"贫民子弟, 交不起束脩!"

你的选择:
  A. 自掏腰包替他们交学费(500金) → 仁义+8, 三个孩子感激
  B. 说服教书先生免费收徒(魅力判定) → 魅力+3, 先生被感动
  C. 自己亲自教他们 → 花费3天时间, 获得"有教无类"称号

后续: 三个月后→其中一个孩子考入学宫→来感谢你→仁义+5
```

**3. 支线「礼之用」** (Lv1)
```
触发: 儒家弟子+在官衙附近
NPC: 两位贵族因为座次问题争吵
场景: 宴会上, 两位贵族都认为自己应该坐上位。"我父亲是大夫!""我祖父是卿!"

你的任务: 用"礼"的原则调解争端
  引用《周礼》中的尊卑次序 → 智略判定
  成功→两人和解→魅力+5
  失败→两人都对你发火→但学到了"礼"在现实中并不总是有效
```

**4. 升级「教化一方」** (→Lv2 门徒)
```
触发: 儒家弟子+仁义≥35 + 智略≥35
NPC: 老儒/当地县令
任务: 前往一座民忠<50的城池→开设学堂→教化百姓

过程(分三步):
  Step1: 说服官府支持(魅力判定, 难度40)
  Step2: 招收学生(贫民优先→仁义+; 只收富家→效率+但仁义-)
  Step3: 三个月后考核——学生学问进步+当地民忠变化
  
成功: 学堂名声远扬→获得称号"儒门教习", 仁义+10
失败: 学堂被当地豪强关闭(他们认为"百姓读书就会不听话")
  → 你需要面对"学问vs势力"的抉择: 妥协/对抗/另寻他处
```

**5. 支线「孝悌之道」** (Lv2)
```
触发: 儒家门徒+在乡村
NPC: 一对兄弟(哥哥虐待弟弟)
场景: 哥哥继承了家产, 把弟弟赶出家门。弟弟在路边哭。

儒家价值观: "孝悌也者, 其为仁之本与"
  兄友弟恭是儒家核心伦理。哥哥不友→该如何处理?

选项:
  A. 以儒家伦理劝导哥哥(魅力判定) → 哥哥悔悟→接回弟弟
  B. 帮助弟弟自立(经营判定) → 弟弟开了一家小店→逐渐富足
  C. 报告官府依法处理 → 哥哥被抓→但弟弟内疚→"他毕竟是我哥哥..."
```

**6. 支线「见利思义」** (Lv2)
```
触发: 儒家门徒+经商时
场景: 你在市集发现一个商人以次充好, 高价卖给不识货的农民。

你的选择:
  A. 当场揭发→商人记恨你→但农民感激→仁义+5
  B. 私下劝告商人→商人惭愧→改邪归正→成为诚信商家→魅力+5
  C. 不管→仁义-3→"这不是我的事"
```

**7. 升级「义利之辨」** (→Lv3 学者)
```
触发: 儒家门徒+智略≥50 + 仁义≥50
地点: 齐国稷下学宫
NPC: 孟子(或其后学) + 齐国大商人

场景: 公开辩论——"义与利孰重?"
  商人: "没有财富, 仁义就是空谈。仓廪实而知礼节!"
  孟子: "上下交征利, 而国危矣。苟为后义而先利, 不夺不餍。"
  商人: "那儒家学者吃什么? 不也要靠商人买卖粮食?"
  孟子: "君子谋道不谋食。"
  商人转向你: "你说! 义重要, 还是利重要?"

你的选择:
  A. 坚持儒家立场(义>利) → 精彩辩论→仁义+15, 但商人阶层好感-10
  B. 调和义利 → 提出"以义制利, 义利兼济"→魅力+10, 获称号"通儒"
  C. 承认利的重要性 → 被逐出师门(儒家不容"利字当头")

奖励: 智略+5, 解锁政策"礼乐复兴"(如果是君主/高官)
```

**8. 支线「孝经传世」** (Lv3)
```
触发: 儒家学者+智略≥55
NPC: 一位老父亲(儿子常年在外征战, 他不识字, 想给儿子写信)

任务: 代笔写信→老父亲口述→你润色成文
  写完后老父亲哭了:"这就是我想说的——但我自己说不出来。"
  
后续: 老父亲请你在村里教其他老人识字
  开设"成人学堂"(3个月)→仁+10, 获得"孝经传习者"称号
```

**9. 支线「诗三百」** (Lv3)
```
触发: 儒家学者+在学宫
NPC: 学宫藏书管理员
任务: 帮助整理学宫散乱的《诗经》竹简
  过程: 300篇竹简散落各处→寻找→整理→分类(风/雅/颂)
  耗时: 7天
  完成: 智略+3, 获得《诗经》完整版竹简
  特殊: 整理过程中发现一首失传的《诗》(随机事件)→贡献给学宫→声望+
```

**10. 升级「周游列国」** (→Lv4 宗师)
```
触发: 儒家学者+魅力≥60 + 仁义≥60
任务: 效仿孔子, 周游列国推广仁政

过程:
  - 选择≥5个国家→依次出使
  - 每到一个国家→向君主献策(提交仁政方案)
  - 可能遭遇: 被采纳(获得该国好感)/被拒绝(被驱逐)/被困(如孔子陈蔡之厄)

特殊事件「陈蔡之厄」:
  在陈国/蔡国边境→被当地军队围困(误以为你是间谍)→粮断绝
  弟子问你: "君子亦有穷乎?"
  你的回答:
    A. "君子固穷, 小人穷斯滥矣。" → 坚守→3天后误会解除→仁义+15
    B. 试图贿赂守卫脱困 → 被发现→"你不是儒家吗?" → 仁义-20
    C. 绝食抗议 → 当地百姓同情→偷偷送粮→你的名声传播

成功: 拜访≥4国→仁义+20, 获得称号"当世仲尼", 全图文化影响力+30%
```

**11. 支线「有朋自远方来」** (Lv4)
```
触发: 儒家宗师+周游列国期间
NPC: 一位外国学者(来自偏远小国), 仰慕儒家而来求学

任务: 接待这位远方学者→与他论学→推荐他到合适的学宫
  对话中你可以了解到他所在国家的风俗→开阔视野
  
奖励: 魅力+5, 该学者成为你的门徒→未来可能成为儒家传承者
```

**12. 终极「万世师表」** (→Lv5 儒家宗师)
```
触发: 儒家宗师+完成"周游列国"+仁义≥85+完成≥1部著作
任务: 编纂儒家经典集大成之作

过程:
  - 收集天下儒家典籍(访问各地学宫/拜访老儒/寻找失传篇目)
  - 整理→注释→编纂(6-12个月专注时间)
  - 期间不能参与战争/长途旅行
  - 每完成一章→触发一次"学者来信"事件(各地学者来信讨论)

完成: 巨著问世→触发世界事件"儒家经典大成"
  效果: 儒家影响力+100%, 后世儒家学者能力+20%
  你被后世尊为"儒家宗师", 名字载入史册
```

## 二、法家 —— 以法治国 (13个任务)

### 学派特色
```
核心价值: 以法治国, 不别亲疏, 不殊贵贱, 一断于法
代表人物: 商鞅/韩非/李斯/申不害
圣地: 秦国咸阳 / 韩国新郑
色调: 玄黑+铁灰
对立: 儒家
```

### 任务链

**1. 入门「徙木立信」** (Lv1 弟子)
```
触发: 智略≥35 + 在秦/韩有官职
场景: 你效仿商鞅。在城南门立一根木头。
      "谁能把此木搬到北门, 赏十金。"
      围观者窃窃私语: "官府又在骗人了..."

你的坚持:
  A. 坚持赏格→无人信→提高到五十金→终于有人搬了→当场兑现
     → 全城震动!"原来官府真的说话算话!" → 入门成功
  B. 强迫士兵去搬 → 百姓:"果然又是强制..." → 失败
  C. 亲自示范→"我自己搬给你们看" → 感动围观者→有人愿意学法

完成: 成为法家"弟子"
奖励: 智略+3, 信义+5, 获得称号"法家弟子"
```

**2. 支线「明法审令」** (Lv1)
```
触发: 法家弟子+在城池官衙
NPC: 三个百姓, 因为不了解新法律而无意间违法
任务: 向他们解释法律条文→让他们明白自己错在哪里→帮助他们改正
  (法家主张"法律公开, 百姓知法")

完成: 三人感激→"原来法家不是只会严刑!" → 该城池治安+3
```

**3. 支线「法不阿贵」** (Lv1)
```
触发: 法家弟子+在城池
NPC: 一个贵族子弟当街欺凌平民
场景: 你的朋友(也是法家弟子)说:"别管闲事, 那是丞相的侄子。"

你的选择:
  A. 依法制止→丞相侄子被带走→你可能得罪丞相→但法家声望+
  B. 记下罪行→收集证据→向上举报→更稳妥但需要时间
  C. 不管→"法不阿贵只是理想..." → 法家声望-
```

**4. 升级「执法不阿」** (→Lv2 门徒)
```
触发: 法家弟子+智略≥45 + 信义≥30
场景: 一桩命案。贵族之子杀了平民。贵族的父亲是朝中重臣。

审判:
  按照法律→杀人者死。
  按照潜规则→贵族赔钱了事。
  朝中有人暗示:"年轻人, 放聪明点。"

你的裁决:
  A. 依法处决→法家声望+20→贵族势力恨你(刺客风险+)
     → 但民众:"法家是真的!" → 获得称号"铁面无私"
  B. 接受贿赂→从轻发落→被法家内部发现→逐出师门
  C. 拖延调查→找到更多罪证→数罪并罚→罪无可赦→既公正又震慑
     → "不是我要杀你, 是法律要杀你。"
```

**5. 支线「告奸者赏」** (Lv2)
```
触发: 法家门徒+在城池
NPC: 一个农民来举报邻居私藏违禁兵器(秦国禁民间兵器)

任务: 核实举报→属实→按照商鞅之法→"告奸者与斩敌首同赏"
  奖励举报人→但同时被举报的全家被连坐→哭声震天
  
你的感受(内心独白触发):
  "法是对的。但为什么我感到不舒服?"
  (这是法家的内在矛盾——严法与人情的冲突)
```

**6. 支线「刑上大夫」** (Lv2)
```
触发: 法家门徒+在官衙
NPC: 一位大夫(官员)贪污被查, 他的同僚集体来求情

场景: 五位官员站在你面前。"法不外乎人情。饶他一次。"
任务: 顶住压力→依法惩处
  成功后→其他官员收敛了许多→贪污率-15%(该城池)
  但你在官场上树敌无数
```

**7. 升级「变法之争」** (→Lv3 学者)
```
触发: 法家门徒+智略≥60 + 在国家中担任要职
场景: 朝堂辩论。你提出变法方案→旧贵族激烈反对。

提案(三选一):
  A. 废除世卿世禄(剥夺贵族世袭特权)
  B. 推行军功爵制(按军功授爵, 不问出身)
  C. 统一度量衡(消除地方差异, 加强中央)

反对者: 旧贵族代表(魅力高, 善于煽动)
你的策略:
  - 强调变法对国家的"利"(功利论证, 法家本色)
  - 揭露反对者的私心(他们反对是因为自身利益受损)
  - 引用商鞅/吴起变法成功的先例

成功: 君主同意试行→法家影响力+30%
失败: 被否决→但"虽败犹荣"→法家内部声望+10
  → 旧贵族记恨→可能排挤/贬官/刺杀你
```

**8. 支线「壹刑」** (Lv3)
```
触发: 法家学者+变法实施后
场景: 变法实施后, 民间有声音:"新法太严了!"

任务: 走访民间→听取百姓对新法的意见
  - 有些抱怨是合理的(法律确实有瑕疵)→修正法律→仁+3(意外收获)
  - 有些抱怨是因为"动了既得利益者的蛋糕"→坚持不改
  - 在"严法"与"良法"之间找到平衡

完成: 法律改进→民忠回升(原先因新法-10)→智略+5
```

**9. 支线「刑弃灰于道」** (Lv3)
```
触发: 法家学者+在都城
NPC: 一个百姓因为往路上倒灰(微不足道的小事)被罚重金

场景: 百姓喊冤:"就倒了一点灰, 至于吗!"
法家理论: "轻罪重罚, 则重罪不至。" (连倒灰都重罚, 人们就不敢犯更重的罪)

你的选择:
  A. 坚持重罚→宣讲法理→围观者半信半疑
  B. 酌情减罚→"法律也需要温度"→但法家内部质疑你"心太软"
  C. 借机宣讲→把这次处罚变成一次普法教育→最佳选择
```

**10. 升级「铸刑鼎」** (→Lv4 宗师)
```
触发: 法家学者+智略≥75 + 所在国完成变法
任务: 编纂法典, 将法律条文铸在鼎上→置于国都广场→"法律公开, 万民共睹"

过程:
  Step1: 编纂法典(整理现有法律+增补新法, 3个月)
  Step2: 铸造刑鼎(花费10000金+精铁+工匠)
  Step3: 公开仪式→向人民宣告:"法不阿贵, 绳不挠曲!"

风险: 旧贵族可能在仪式当天发动叛乱→你需要布置兵力防范
成功: 该国治安+30%, 贪污率-50%, 法家影响力+50%
奖励: 称号"法家宗师"
```

**11. 支线「以刑去刑」** (Lv4)
```
触发: 法家宗师+铸刑鼎后
场景: 有人质疑:"严刑峻法, 是否太残忍?"

任务: 撰写一篇文章回应——"以刑去刑"论
  "今日之严刑, 正是为了来日无刑。
   当人人都知道违法的代价, 就没有人违法了——
   那时的法律, 形同虚设——因为没有人需要它。"
  
完成: 智略+5, 你的论著被法家奉为经典
```

**12. 支线「韩非遗书」** (Lv4)
```
触发: 法家宗师+韩非已死(历史事件)+找到韩非遗稿
场景: 你在秦国档案库中发现韩非在狱中写的最后一篇文章

内容: 韩非反思法家——"我为韩国公子, 却无法说服韩王变法。
      我的学说被敌国(秦)采纳。这是法家的成功, 还是失败?"
      
你的任务: 为韩非完成这部未完成的遗著
完成: 智略+8, 获得《韩非子·终篇》(韩非+你的合著), 法家思想更完整
```

## 附: 学派声望与机制 (WoW 60级声望系统)

### 学派声望等级

每个学派独立的声望条(WoW式):
```
[仇恨] 0-3000   → 学派敌对, 无法加入(加入前状态, 不参与任务解锁)
[中立] 0-6000     → 可加入, 基础任务
[友善] 6000-12000 → 中级技能+绿品配方
[尊敬] 12000-18000 → 高级技能+蓝品配方+进阶任务
[崇敬] 18000-24000 → 宗师任务+紫品配方
[崇拜] 24000-30000 → 终极称号+金品配方+学派专属外观

(与任务模板与配置表.csv「学派声望表」一致, 共5档)
```

### 声望获取途径
```
学派任务: +100-500/次 (一次性)
学派日常: +50-150/天 (可重复)
捐献物资: 每1000金≈+250
  儒家→竹简/书籍; 法家→金; 墨家→木材/石材(守城)
  道家→药材; 兵家→兵器/战马
达成学派成就: +500-1000(里程碑)
击杀对立学派NPC: +5-25(递减)
```

### 声望联动 (刷A降B)
```
儒家↑ → 法家↓(-50%获取速率)  |  法家↑ → 儒家↓(-50%)
墨家↑ → 名家↓(-25%)            |  道家↑ → 法家↓(-25%)
兵家↔ 法家↑(互相促进, +25%)    |  杂家：不受任何联动影响
```

```

法家: 「审理案件」声望+50 / 「巡查执法」声望+75 / 「修订律条」声望+100
```
