# 人生路线任务 (WoW职业任务式进阶)

## 设计目标

> 对标《魔兽世界》的职业任务(战士姿态/盗贼毒药/法师传送)。六条人生路线=六个"职业"。每条路线的关键里程碑不是"自动解锁"的——需要完成专属的"职业任务链"(类似WoW战士30级狂暴姿态任务)。某些高级技能/身份需要特定掉落物品触发, 类似盗贼毒药职业任务的"需要自己去偷/制作"。

## 路线进阶机制 (WoW Attunement式)

### 阶段解锁条件

```
每条路线三个阶段, 进入下一阶段需要:

阶段1→阶段2 (Lv1→Lv20):
  ☑ 完成该路线入门任务链(3-4步)
  ☑ 满足阶段2属性门槛(各路线不同, 以310/122 4.2为准):
     霸道: 统率≥40+武勇≥35 | 王道: 魅力≥50+智略≥55 | 侠道: 武勇≥55+武名≥35
     商道: 经营≥55+资产≥2万 | 匠道: 工艺≥55 | 隐道: 智略≥60+学派≥3级
  ☑ 完成路线标志性成就(1个)
    →霸道: 指挥1场战斗/王道: 完成1次外交/侠道: 完成5个赏金
    →商道: 赚1000金/匠道: 锻造绿品装备/隐道: 完成1部著作
  
阶段2→阶段3 (Lv20→Lv40):
  ☑ 完成该路线进阶任务链(4-5步, 包含1个精英任务)
  ☑ 满足阶段3属性门槛(各路线不同, 以310/122 4.2为准):
     霸道: 统率≥75+爵位≥中卿 | 王道: 魅力≥75+信义≥70 | 侠道: 武勇≥80+仁义≥55
     商道: 经营≥80 | 匠道: 工艺≥80 | 隐道: 智略≥85
  ☑ 完成路线标志性成就(3个)
  ☑ 获得路线专属掉落物品(类似"职业任务物品"):
    →霸道: 「将军令」(君主授予, 统率≥60)
    →侠道: 「刺客印记」(刺客组织授予, 完成3次暗杀)
    →商道: 「商会印信」(加入商会, 资产≥20000)
    →匠道: 「宗师认证」(任一铁匠宗师授予, 工艺≥65)
  
阶段3→终极 (Lv40→Lv60):
  ☑ 完成3个精英任务(Boss级)
  ☑ 已满足阶段3属性门槛(终极不再设置更高的属性墙)
  ☑ 路线声望达到[尊敬](12000+)
  ☑ 完成路线终极任务链(类似WoW的"史诗任务")
```

### 路线专属掉落(类似战士姿态符文/盗贼毒药配方)

```
每个路线有"世界掉落"的任务物品, 拾取后右键→触发路线专属任务:

霸道:
  「残破的虎符」(古战场掉落, 0.5%) → "虎符的召唤" → 发现隐藏的远征军
  「白起的剑穗」(白起相关掉落, 1%) → "杀神的遗产" → 学习白起的战术

侠道:
  「刺客的匕首」(暗杀目标掉落, 2%) → "前一个刺客" → 追踪前辈的足迹
  「易水边的石头」(易水区域采集, 5%) → "荆轲的回忆" → 感悟刺客之道

商道:
  「吕不韦的算盘」(赵国邯郸市集, 随机出现, 1%) → "奇货可居" → 投资任务
  「破损的账本」(击败商队劫匪掉落, 3%) → "被劫的商路" → 开辟新商路

匠道:
  「欧冶子的锤印」(各地铁匠铺, 0.5%) → "铸剑师的传承" → 学得特殊配方
  「陨铁碎片」(夜间流星事件, 极罕见) → "天外之铁" → 打造特殊武器

隐道:
  「鬼谷残页」(学宫书架, 1%) → "鬼谷子的秘密" → 寻找鬼谷
  「孔子的断简」(鲁国孔庙, 3%) → "先师的遗训" → 智略大幅提升
```

### 声望与路线进阶

```
路线声望(WoW声望式):
  [中立] 0-6000   → 可接初级任务
  [友善] 6000-12000 → 路线专属商店(绿品装备)
  [尊敬] 12000-18000 → 进阶任务+蓝品装备
  [崇敬] 18000-24000 → 精英任务+紫品装备
  [崇拜] 24000-30000 → 路线终极奖励(金品装备/专属称号)

路线声望获取:
  完成该路线任务: +100-500(一次性)
  该路线日常/周常: +50-250/次
  达成路线成就: +500-1000(里程碑)
  捐献该路线相关物资: 每1000金≈+250
  
  特殊: 做对立路线的任务→当前路线声望微降(如: 做霸道任务→隐道路线声望-10)
```
