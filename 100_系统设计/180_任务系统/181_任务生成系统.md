# 任务生成系统 (WoW 60级经典机制)

## 设计目标

> 对标《魔兽世界》经典旧世的任务生成逻辑。酒馆任务的"击杀12个黑风寨山贼"不是随机数字——每个数字都经过野外怪物密度和刷新时间的计算。护送任务的路线经过巡逻怪的刷新点平衡。精英任务需要明确的带兵/带兵数量标注。稀有掉落触发任务有明确的掉落率和触发条件。

---

## 一、Kill任务 (击杀X个Y)

### 数量计算公式
```
所需击杀数 = 目标区域怪物数量 × 0.3(覆盖率) × 难度系数

怪物数量: 目标区域该怪物刷新点×每组数量
覆盖率: 玩家需要清掉该区域约30%的怪物→有"清场"感但不需要全清
难度系数: 灰色0.1/绿色0.2/黄色0.3/橙色0.5/红色0.8

示例: 黑风寨有40个山贼(8组×5)→黄字任务→40×0.3×0.3≈12个
"击杀黑风寨山贼×12" ✓

错误: "击杀黑风寨山贼×40"(全清→太肝)
      "击杀黑风寨山贼×3"(太简单→无成就感)
```

### 精英Kill任务
```
精英标记: [精英]标签+红色/骷髅颜色
数量: 普通Kill数量的1/5~1/3(精英怪密度低得多)
要求: 建议带兵/带兵(标注推荐人数/兵力)

示例:
  "击杀黑风寨头目·赵大[精英]"(橙色, 建议带兵≥50)
  "击杀龙渊守护者·巨鳄[精英Boss]"(骷髅, 需要≥500兵力)
```

### 刷新联动
```
任务Kill数量需考虑: 目标怪物的刷新时间
  普通怪物: 5分钟刷新
  任务怪物: 如果生成时检测到高密度→临时提高刷新率(+50%)
  精英怪物: 15分钟-72小时不等(不调整——稀有性本身就是价值)
```

## 二、Collect任务 (收集X个Y)

### 掉落率标准
```
| 物品类型 | 掉落率 | 需求数量 | 需杀数(期望) | 时间(分钟) |
|---------|--------|---------|------------|-----------|
| 常见(兽皮/草药) | 80-100% | 8-12 | 10-15 | 5-8 |
| 常见(矿石/木材) | 100%(采集) | 6-10 | 6-10(采集点) | 3-5 |
| 普通(兵器残骸) | 40-60% | 6-10 | 12-20 | 8-12 |
| 稀有(特殊材料) | 10-25% | 1-3 | 8-20 | 10-20 |
| 任务专属 | 100%(任务激活后) | 1-5 | 1-5 | 2-5 |

反肝设计: 如果玩家击杀超过2倍期望数仍未集齐→保底机制触发→掉落率提升至100%
```

### 掉落物品触发任务
```
WoW经典机制: 拾取特定物品→右键阅读/使用→开启隐藏任务

触发物品类型:
  「旧竹简」(古墓/学宫掉落, 5%→右键阅读→开启探索任务)
  「破损的密信」(战场/NPC身上掉落, 3%→开启调查任务)
  「染血的家书」(击杀特定NPC掉落, 10%→开启复仇/救援任务)
  「名剑残片」(古战场稀有刷新点, 1%→开启名剑任务链)
  「学派秘籍残页」(学宫书架交互, 2%→开启学派进阶任务)

触发后: 任务出现在日志→但不能追踪(无GPS)→靠文本自己找
```

## 三、Escort任务 (护送)

### 路线设计
```
护送NPC路线必须: 经过1-3个潜在遭遇点(战斗点)
不要让NPC走"最安全"的路——让NPC走"故事最有趣"的路

遭遇点设计:
  ①必定遭遇(1-2处): 保证任务有"护送"的感觉
  ②概率遭遇(1-2处): 30-50%概率触发额外战斗→惊喜/刺激
  ③环境障碍(1处): 不是战斗但需要互动(如: 路被倒树挡住→需要清理)

NPC行为:
  跟随距离: 5-10m(太近挡路/太远丢)
  战斗参与: 弱(NPC攻击力=玩家20%, 不抢玩家风头)
  非战斗: 有台词(讲他的故事→让护送不只是走路)
  死亡: 任务失败→需要重新开始(不是"NPC原地复活")
```

### 护送难度标记
```
| 难度 | 遭遇数 | 敌人等级 | 单人? |
|------|--------|---------|-------|
| 绿色 | 1必+0随 | 绿 | 可 |
| 黄色 | 1必+1随 | 黄 | 可 |
| 橙色 | 2必+1随 | 橙 | 建议带兵 |
| 红色 | 2必+2随 | 红+精英 | 必须带兵/带兵 |
```

## 四、Elite/Boss任务

### Boss设计标准
```
精英Boss必须:
  ☑ 独特名字(不是"山贼头目", 是"黑风寨·赵大")
  ☑ 掉落至少1件固定独特物品(蓝品质+)
  ☑ 有1-2个可读懂的技能/机制(不是无脑平A)
  ☑ 刷新时间明确(普通精英15-30min/稀有精英12-72h)
  ☑ 建议带兵标注: "建议X人带兵/带兵≥X"

Boss掉落表:
  100%掉落: 「赵大的首级」(任务物品)
  80%掉落: 蓝品质武器×1(随机词缀)
  20%掉落: 紫品质材料×1
  5%掉落: 「赵大的藏宝图」(开启隐藏宝藏任务)
  1%掉落: 「名剑碎片·鱼肠」(极稀有, 名剑任务物品)
```

## 五、Timed任务 (限时)

```
限时任务类型:
  ①软限时(绿色): "在X天内完成" →超时→奖励减少50%
  ②硬限时(黄色): "在X天内完成" →超时→任务失败
  ③紧急限时(红色): "在X时辰内完成!" →超时→NPC死亡/城池陷落
  ④倒计时限时(橙色): "坚持X天!" →防守任务

时间计算:
  基础时间 = (路途时间+战斗时间+交互时间)×1.3(容错率)
  路途时间: 距离(里)/(移速(里/天))
  战斗时间: 每场战斗5-15分钟(游戏时间: 约1-3游戏小时)
```

## 六、Daily/Repeatable任务 (日常/周常)

```
日常任务(Daily, 蓝色感叹号):
  每个城池每日刷新2-4个日常(酒馆1-2+官府1+商会0-1)
  奖励: 少量金+少量声望(25-50)
  可重复: 是(但同一天同一任务只能做一次)

周常任务(Weekly, 紫色感叹号):
  每个区域每周1-2个周常
  类型: 精英击杀/大型护送/防守
  奖励: 大量金+声望(200-500)+概率蓝/紫装备

世界任务(World Quest, 金色感叹号):
  不定期刷新(世界事件触发)
  奖励: 独特装备/大量声望
  全服可见(谁先完成归谁, 或所有人都可完成)
```

## 七、Breadcrumb任务 (面包屑引导)

```
跨区引导:
  在A区完成某任务→NPC说"你去X城的话, 找YYY, 他可能需要帮忙"
  →任务日志记录→到达X城→NPC头顶出现黄色!

低→高等级引导:
  Lv10区域完成后→自动触发→"听说北方的战事更激烈, 那里需要你。"
  →地图上高亮Lv15-20区域

跨路线引导:
  你在霸道路线→某NPC说"只会打仗是不够的——你应该去学学经商。"
  →引导你发现商道路线
```
