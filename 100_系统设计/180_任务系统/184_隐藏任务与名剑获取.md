# 十大名剑获取任务 (魔兽世界式完整任务设计)

## 设计原则

> 对标《魔兽世界》传奇武器任务线。每把名剑14-19步史诗任务链，含: 具体NPC姓名/刷新条件、任务道具名称/获取方式、精英怪掉率/刷新周期、交互机制/判定条件、阶段奖励/中间形态。149个任务×66个关键NPC×100+独特道具。

---

## 一、湛卢 —— 仁道之剑 (19个任务)

### 名剑属性
```
品质: 传说(金) | 伤害: 100 | 速度: 0.28 | 破甲: 30%
特效: 自动完美格挡(无需方向匹配) + 格挡反击+50% + 仁义+8
绑定: 灵魂绑定
```

### 任务链

**任务1「酒馆奇闻」**
```
类型: 对话
NPC: 说书人·公孙老(楚国/吴越Lv3+城池酒馆, 20-24时刷新)
目标: 听公孙老讲湛卢故事→获得「说书人的残卷」
提示: 每天讲不同的片段, 需听3次(间隔≥1天)才能集齐完整线索
```

**任务2「古籍考证」**
```
类型: 收集
目标物品:
  ①「越绝书·记宝剑」(学宫书架交互, 随机触发, 概率15%/次)
  ②「吴越春秋·残页」(吴国故地学者NPC好感≥30赠予)
  ③「欧冶子铸剑谱·残页」(楚国铁匠铺, 工艺≥40后铁匠展示)
集齐→找学宫藏书吏·简伯拼合→「湛卢考」
```

**任务3「樵夫指路」**
```
类型: 对话
NPC: 山中樵夫·邓伯(会稽山白天出没)
道具: 「邓伯的草图」→解锁隐藏地点「湛卢竹林」
```

**任务4「竹林试炼」**
```
类型: 探索/解谜
地点: 湛卢竹林(隐藏)
三重关:
  ①曲径: 选"更窄更暗"的岔路3次
  ②伤鹿: 使用「金创药」(药铺10金)救治→通过; 杀死→永久失败
  ③铭文石台: 回答"求湛卢"→石门开启
无掉落惩罚, 选错绕回起点
```

**任务5「不速之客」**
```
类型: 对话/分支
NPC: 湛卢隐士·季然(竹林小屋)
随机三问(抽二): "杀过人吗?/最对不起谁?/天下太平后做什么?"
根据回答决定后续态度→获得「季然的客人」身份
```

**任务6「砍柴挑水」**
```
类型: 日常×3天
Day1: 收集「干柴」×10(竹林区域采集)
Day2: 用「空竹筒」×3(季然给)去竹溪灌「竹筒水」
Day3: 扫尘→发现「旧竹简」(季然日记)
完成: 仁义+3, 解锁继续
```

**任务7「季然的日记」**
```
类型: 阅读/信息
物品: 「旧竹简」→发现季然年轻时因杀人而让湛卢失去光芒
交给季然→触发"让湛卢重新发光"
```

**任务8「山贼之德」**
```
类型: 交涉(不用武力)
地点: 黑风寨
NPC: 山贼头目·赵大
路线A「调查背景」: 找村长·老周→得知被苛税落草→找县令·王甫(魅力60或贿1000金)→拿「减税令」→山贼解散
路线B「以德服人」: 每日对话×7天→Day7赵大被感动→解散
```

**任务9「湛卢初鸣」**
```
类型: 互动
湛卢发出蓝光→获得「微光的湛卢」(临时版, 伤害60, 特效未激活)
```

**任务10「三件仁者遗物」**
```
类型: 收集
①「万民血书」: 灾荒时捐粮≥5000石→灾民赠→光+30%
②「祖传古玉」: 城池民忠≥90时与老人对话→获赠→光+30%
③「仁者之誓」: 向季然宣誓"不杀降/不屠城/不欺弱"→光满→「湛卢」正式版
```

**任务11-13「历代剑主遗产」**
```
任务11「第一任·护国」: 古战场→清理藤蔓→「墨汁」+「宣纸」拓印石碑→「护国」剑意(守城翻倍)
任务12「第二任·恕道」: 咸阳白起旧营→三片「信笺碎片」(遗骸旁/书简堆/树下, 第三片需「铲子」挖掘)→拼合→「恕道」剑意(反击+30%)
任务13「第三任·释怀」: 季然的仇人·廷尉公孙鞑→刺杀(破誓)/对话了解真相(释怀)/调解道歉(双倍奖励)
```

**任务14-16「剑心通明(三日禅修)」**
```
任务14(Day1)「放下剑」: 湛卢放石台一整天→帮村民干农活
任务15(Day2)「放下名」: 匿名帮3村民(修屋顶/挑水/教识字)→不留名
任务16(Day3)「拿起剑」: 季然木剑突袭→选择闭眼→湛卢自动格挡→"剑心通明"
奖励: 「湛卢剑鞘」(饰品, 仁义光环+10)
```

**任务17-19「传承」**
```
任务17「公孙逸求剑」: 游侠NPC在酒馆出现→考验他的仁义→选择传或拒
任务18「季然的信」: 30天后信使送绝笔信→回竹林→季然已去→「季然遗物玉佩」
任务19「仁者无敌」: 仁义≥95+从未破誓→剑身浮现"仁者无敌"→完美格挡100%+体力零耗
```

## 二、鱼肠 —— 刺客之剑 (17个任务)

### 名剑属性
```
品质: 传说(金) | 伤害: 90 | 速度: 0.22 | 破甲: 35%
特效: 刺击+50%, 袖中藏剑(隐蔽携带), 暗杀伤害+100%
绑定: 灵魂绑定
```

### 任务链

**任务1「说书人的故事」**
```
类型: 对话
NPC: 说书人·言老(吴越Lv3+酒馆, 夜晚)
听专诸刺王僚→获得「说书人的故事记录」
线索: "专诸后人可能在姑苏城外渔村"
```

**任务2「渔村寻访」**
```
类型: 探索
地点: 姑苏外三个渔村(石湖/太湖/笠泽)
NPC: 各村村长→只有笠泽村村长知道专婆婆住处
提示: "别打扰她, 她不喜欢外人"
```

**任务3「湖畔茅屋」**
```
类型: 对话
NPC: 专婆婆(75岁, 笠泽湖东岸)
条件: 侠道≥阶段2 或 仁义≥50 或 武勇≥60→任一满足→获准入屋
```

**任务4「专诸遗训」**
```
类型: 阅读/宣誓
物品: 「专诸遗训」(竹简, 专婆婆给)
内容: "三不杀(仁者/无辜/无名)·三必杀(暴君/民贼/仇雠)"
要求: 在专婆婆前宣誓遵守→获「专婆婆的初步认可」
```

**任务5「藏剑试炼」**
```
类型: 潜行
地点: 姑苏县衙
物品: 「试炼短剑」(专婆婆给)+「夜行衣」(布庄买, 潜行+20%)
目标: 将短剑放在县令书案→全程不触发警报→出来
失败: 等3天重试
```

**任务6「识人试炼」**
```
类型: 调查/判断
目标: 判断三人该杀与否:
  ①县令·王甫: 调查→百姓说好→不该杀
  ②恶霸·钱三: 市集打听→核实罪证→该杀(民贼)
  ③死囚·赵平: 狱卒传闻→查真凶→不该杀(无辜)
正确≥2/3→「专婆婆正式认可」+「专诸墓钥匙」
```

**任务7「水下墓道」**
```
类型: 探索
地点: 会稽山·专诸墓(隐藏)
物品: 「水下呼吸药剂」(药铺50金或自制: 鱼鳔×2+药材×1)
水中→拔「石剑」→水位降→通过
```

**任务8「壁画之室」**
```
类型: 互动/选择
六幅壁画: 专诸刺王僚全过程→最后一行字"你愿付出同样代价吗?"
选择"愿意"→门开; 犹豫→门半开(需再确认)
```

**任务9「石盒」**
```
类型: 互动
墓室中央→打开石盒→「鱼肠」(临时版, 伤害50, 特效未激活)
剑身铭文:"以我之血, 换彼之血。以我之命, 换天下之公。"
```

**任务10「调查恶官」**
```
类型: 调查/收集证据
目标NPC: 恶官·司马横
罪证收集:
  ①「地契·被篡改」: 找被占田农民·老张→旧箱子里拿原件
  ②「假账本」: 夜间潜入官仓(潜行)或贿赂仓管(500金)
  ③「举报信·原件」: 找寡妇·何氏→需保护她不被灭口
集齐→「司马横罪证三件套」
```

**任务11「一击必杀」**
```
类型: 暗杀
目标: 夜潜司马横府邸书房→鱼肠袖中滑出→一击毙命
要求: 必须不被发现(若触发警报→鱼肠黯淡→需重建信任)
完成: 鱼肠发热→「鱼肠」(正式版, 伤害90, 特效激活)
```

**任务12「专诸的宿敌」**
```
类型: 对话/任务接受
NPC: 专婆婆→告知专诸死前未完成的刺杀
目标: 随机选择一个残暴度≥70的君主/高官→替专诸完成
```

**任务13「潜伏」**
```
类型: 工作/情报
前往目标国→成为目标的门客/侍卫(完成该国基础任务建立信任)
潜伏15-30天→观察目标作息→记录弱点→寻找时机
```

**任务14「一击必杀(致敬专诸)」**
```
类型: 暗杀
场景: 目标举办宴会→你端鱼上前→从鱼腹中抽出鱼肠(对专诸的致敬)
一击→目标倒下→殿中大乱→趁乱逃脱(或被捕)
完成: 「专诸的认可」→鱼肠完全觉醒
```

**任务15「传剑」**
```
类型: 选择
触发: 年龄≥50或完成专诸遗愿后
选择: 传剑给年轻刺客/传子嗣/封存
```

**任务16「鱼肠的真相」**
```
类型: 自动触发
完成全部任务后→剑身显新铭文:
"以暴制暴, 非道也。不得已而为之。愿后世——不再需要我。"
```

**任务17「刺客的终章」**
```
类型: 成就
完成全部→获得成就「鱼肠之主」
效果: 暗杀不再消耗体力, 暗杀成功后必逃脱
```

## 三、巨阙 —— 力士之剑 (16个任务)

### 名剑属性
```
品质: 传说(金) | 伤害: 120 | 速度: 0.55 | 破甲: 40%
特效: 重击必破防+击退3m+溅射2m, 武勇+10, 体力消耗-20%
绑定: 灵魂绑定
```

### 任务链

**任务1「铁矿山传说」**
```
类型: 对话
地点: 韩国宜阳·铁矿山
NPC: 宜阳铁匠·欧冶宏(欧冶子后裔, 白天在铁匠铺)
对话→得知:"巨阙——重一百二十斤。山崩后被埋了。非力士不能举。"
获得: 「巨阙考」(记录大致位置)
```

**任务2「山崩遗迹」**
```
类型: 探索/交互
地点: 宜阳铁矿山·北坡(隐藏标记)
目标: 用「铁镐」(铁匠铺20金)清理碎石→露出巨阙剑柄
交互→提示:"太重了!" (武勇判定, 需要≥90)
不达标→无法拿起→触发任务3
```

**任务3「力士修行」**
```
类型: 信息收集
NPC: 欧冶宏:"秦国有个大力士叫孟贲——死了。去找他后人。"
    或酒馆打听"大力士"→线索指向孟刚
```

**任务4「孟贲后裔」**
```
类型: 对话
地点: 秦国·孟家山村(咸阳北200里)
NPC: 孟氏力士·孟刚(孟贲之孙, 屠夫, 白天在肉铺)
对话→孟刚:"想举那把剑? 先过我这关。"
开启训练营
```

**任务5-9「大力士训练营」(5步训练)**
```
任务5「举石锁」
  物品: 「石锁·100斤」(孟刚提供)
  目标: 举起并坚持30秒(连续按键判定)
  提交: 「石锁举重记录」

任务6「拖巨木」
  地点: 山村西·伐木场
  物品: 「巨木·赤松」(伐木场交互获取)
  目标: 拖行500m→回到孟刚处
  体力消耗: 全程~50%体力

任务7「角力」
  NPC: 孟刚
  目标: 与孟刚角力(武勇+力量判定)
  失败: 3天后重试(每次失败武勇临时+3, 叠加到成功)
  成功: 孟刚拍肩:"有两下子!"

任务8「负重行军」
  物品: 「负重石·100斤」
  路线: 孟家山村→宜阳铁矿山(15km)
  目标: 背着负重石走完全程→不可骑马/坐车
  耗时: 约1天(游戏时间)

任务9「最终测试」
  地点: 宜阳铁矿山·北坡
  目标: 再次尝试举起巨阙→成功!
  获得: 「巨阙」(临时版, 伤害70, 无特效)
```

**任务10「劈石」**
```
类型: 互动(判定)
地点: 宜阳铁矿山·试剑坪
物品: 「试剑石」(特殊交互对象)
目标: 用巨阙重击劈开试剑石(重击判定, 需要3次成功蓄力重击)
成功: 试剑石裂开→巨阙微微发光→特效部分激活
```

**任务11「碎甲」**
```
类型: 战斗
目标: 在战场上用巨阙击碎一面「铁盾」或「铁甲」
敌人: 持盾的魏武卒(魏国)/铁甲秦锐士(秦国)
完成: 巨阙剑身泛起金色微光
```

**任务12「古战场的剑痕」**
```
类型: 探索
地点: 伊阙古战场(白起斩首24万处)西侧
目标: 找到三块有巨大剑痕的「战场石」
  ①伊阙北入口
  ②伊阙中央高台
  ③伊阙南侧河岸
每块石头交互→巨阙产生共鸣→获得「剑痕的记忆」

完成: 领悟「破军」剑意(溅射范围+1m)
```

**任务13「前任剑主之子」**
```
类型: 对话/战斗
触发: 完成「剑痕的记忆」→一个陌生人找到你
NPC: 「力士·铁臂」(巨阙前任剑主之子, 精英NPC)
场景: "那把剑——是我父亲的。还给我。"

选择:
  A. 接受对决→战胜他→获得他的尊重→"你比我更配它。"
  B. 拒绝→他会跟踪你→某天偷袭(强制战斗)
  C. 对话→了解他父亲的故事→约定对决(更体面)
```

**任务14「力之对决」**
```
类型: 精英战斗
对手: 力士·铁臂(Lv45精英, 持双手巨锤, 伤害高但速度慢)
战斗机制:
  - 铁臂的重击可以被巨阙格挡(格挡成功→反击窗口)
  - 铁臂生命<30%→狂暴(攻击速度+50%, 防御-30%)
  - 不能使用暗器/弓箭(力士对决的规矩)
胜利: 铁臂跪下→"...我服了。"
```

**任务15「举重若轻」**
```
类型: 对话/领悟
NPC: 铁臂(战败后)
铁臂:"我练了十年——为什么你七天就做到了?"
你的回答触发最终觉醒:
  A. "力量不在肌肉——在心。"
  B. "你太想证明自己了。剑不需要证明什么。"
  C. "巨阙选择了我——就像它选择了你父亲。不是谁更强。"

无论选什么→巨阙完全觉醒→「巨阙」(正式版, 伤害120, 全特效激活)
```

**任务16「力士之证」**
```
类型: 成就
完成全部→获得成就「巨阙之主」
效果: 体力消耗额外-10%(与巨阙自身-20%叠加→共-30%)
解锁武器外观「黄金巨阙」(纯外观, 炫耀用)
```

## 四、太阿 —— 威道之剑 (18个任务)

### 名剑属性
```
品质: 传说(金) | 伤害: 110 | 速度: 0.30 | 破甲: 25%
特效: 每3次命中→第4击必暴击(200%)/统率+5+武勇+5/全军士气+10(光环)/敌军士气-5
绑定: 灵魂绑定
```

### 任务链

**任务1「学宫古书」**
```
类型: 收集/阅读
地点: 任意Lv3+学宫
物品: 「楚王铸剑记」(学宫书架交互, 概率10%/次)
内容: "太阿, 欧冶子与干将为楚王所铸。威道之剑, 剑成而精光贯天。"
获得线索: 太阿随楚王下葬→可能在楚王陵中
```

**任务2「楚国贵族」**
```

提示: 这是展示你地位的机会——也是纯钧可能出现的场合
```
