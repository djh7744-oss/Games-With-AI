# 任务系统概述 (魔兽世界60级年代设计哲学)

> **首发单机**: 本任务系统为单人游戏设计。精英/Boss任务鼓励玩家率领NPC军队作战(带兵系统)，而非依赖其他玩家组队。所有难度标记基于"单人+兵力"而非"多人组队"。

## 设计哲学

> "任务不是待办清单。任务是故事。"——暴雪60年代任务设计黄金法则。本任务系统对标《魔兽世界》经典旧世的任务设计精髓：**不给GPS导航、精英区需要带兵、职业任务体现身份差异、长线链跨越整个大陆、稀有刷新让世界充满期待、声望是硬通货、野外掉落开启隐藏任务**。

## 十大设计支柱 (WoW 60级核心法则)

| 法则 | WoW经典体现 | 七国应用 |
|------|-----------|-----------------|
| **1. 无导航/靠阅读** | 无地图标记, 靠任务文本找NPC | 无GPS, 靠NPC对话+环境线索+古书指引 |
| **2. 精英区/高难挑战** | 霍格/阿鲁高之子/精英龙 | 山寨头目/古墓守护者/名将Boss, 建议率领精兵强将 |
| **3. 长线链跨区** | 失踪的使节/林克的回旋镖 | 名剑任务链跨越5国/学派任务从入门到宗师 |
| **4. 职业/身份专属** | 战士姿态/法师传送/盗贼毒药 | 六条人生路线各有专属任务链 |
| **5. 稀有刷新/等待** | 纳兹加克王子/稀有精英 | 隐士随机出现/古墓入口仅特定时间开启 |
| **6. 声望驱动** | 木喉要塞/银色黎明 | 学派声望决定可学技能/国家声望决定可接任务 |
| **7. 掉落物品触发** | 破损的日记/密信开启任务 | 古书残页/旧竹简/战场遗物右键阅读→开启隐藏任务 |
| **8. 护送/防守** | 护送小鸡/Tarren Mill防守 | 护送商队/防守城池/保护NPC使臣 |
| **9. 精英养成** | 猎人宠物/术士恶魔 | 炼专属兵器/训练副将/招募游侠同伴→成长系统 |
| **10. 世界感/真实** | NPC有作息/怪物有生态 | 平民AI作息/流寇只在夜间出没/集市早市晚市 |

### 按来源分

| 来源 | 标识 | 刷新 | 特色 |

## 区域难度与等级分布

### 新手区 (Lv1-15) — 安全, 教学

```
区域: 各出生国新手村(对应六出身起始位置)
难度: 灰色~绿色(敌人比玩家低0-3级)
精英: 无
任务类型: 基础教学(战斗/采集/对话/护送入门)
代表:
  - "帮老农驱赶田里的野猪×5" (Kill, 白色品质奖励)
  - "替铁匠送剑到镇上市集" (Delivery)
  - "寻找失踪的牛" (Explore→发现隐藏的小山谷)
```

### 初级区 (Lv10-25) — 普通, 单人

```
区域: 各国内陆(非边境)
难度: 绿色~黄色
精英: 极少(个别Lv20精英怪, 可单人挑战)
任务类型: 完整的个人战斗任务/初级探索
代表:
  - "剿灭白石山流寇×15" (Kill)
  - "护送李氏商队" (Escort)
  - "收集草药×10" (Collect, 为药铺)
  - "调查老张家的怪声"(→发现隐藏地下室→掉落「旧竹简」→开启隐藏任务)
```

### 中级区 (Lv20-40) — 挑战, 建议带兵

```
区域: 各国边境/关隘/古战场
难度: 黄色~橙色
精英: 开始出现(山寨头目/古墓机关兽/战场怨魂, 需要带兵或召同伴)
稀有: 稀有NPC/精英开始出现(刷新周期12-48小时)
任务类型: 完整的军团战斗任务/学派进阶任务
代表:
  - "攻破黑风寨·山寨头目·赵大[精英]" (Elite, 建议带兵)
  - "探索专诸墓"(三关→最终boss-like石剑机关) (Elite Explore)
  - "护送使臣穿越战区" (Escort, 限时, 需要护卫队伍)
  - "寻找龙渊山" (跨区长链→从楚国→巴蜀→龙渊山, 10+步骤)
```

### 高级区 (Lv35-55) — 危险, 必须带兵

```
区域: 古战场深层/敌国腹地/龙脉/秘境
难度: 橙色~红色(精英)
精英: 密集(古墓Boss/龙兽/名将[精英])
稀有: 极其稀有(刷新周期3-7天)
任务类型: 名剑任务/灭国战役任务/学派终极任务
代表:
  - "击败龙渊守护者·巨鳄[精英Boss]" (Elite Boss, Lv45, 需要≥500兵力, 极高挑战)
  - "守卫函谷关·秦军精英来袭" (Defense, 30天, 红色难度)
  - "寻找鬼谷·鬼谷子[唯一]"(全服隐藏, 找到的人屈指可数)
  - "破解楚王陵机关"(全程Elite, 需要智略≥70或带兵互补)
```

### 终极区 (Lv50-60) — 史诗, 大量带兵

```
区域: 最终战场/帝王陵墓/统一战争
难度: 橙色~骷髅(Boss级)
精英: Boss级(名将/机关大将军/龙神幻影)
任务类型: 统一战争/路线终极任务/名剑最终觉醒
```

## 声望系统 (WoW式)

### 学派声望

```
声望等级(与任务模板与配置表.csv「学派声望表」一致, 共5档):
  [中立] 0-6000     → 可加入学派, 基础任务
  [友善] 6000-12000 → 进阶任务+初级技能
  [尊敬] 12000-18000 → 高级任务+高级技能+蓝品配方
  [崇敬] 18000-24000 → 宗师任务+紫品配方
  [崇拜] 24000-30000 → 终极称号+金品配方+专属外观

注: 加入学派前为[仇恨]0-3000(仅影响对话与敌意行为, 不参与任务解锁, 见186)

声望获取:
  任务完成: +100-500(一次性)
  捐献物资: 每1000金≈+250
  日常任务: +50-150/天(可重复)
  击杀对立学派NPC: +5-25(递减)
```

### 国家声望

```
七国独立声望(可同时刷多个国家)
影响: 可接任务等级/可购买装备/征兵价格/外交成功率
获取: 完成该国任务/战争胜利/外交贡献/捐献物资
```

## 稀有刷新机制

### 稀有NPC

```
定义: 独特名字, 比普通NPC强2-3倍, 掉落独特物品
刷新: 12-72小时不等(不同稀有NPC有不同的刷新周期)
位置: 固定区域(非固定坐标)
首次击杀: 100%掉落独特物品
后续击杀: 掉落独特物品概率降至5-20%

示例:
  「隐士·季然」: 湛卢竹林, 刷新48h, 掉落「季然的日记」(必掉, 首次)
  「战场怨魂·赵括」: 长平古战场(夜晚), 刷新72h, 掉落「赵括的残破兵符」
  「流浪剑客·公孙逸」: 随机城池酒馆, 刷新24h, 掉落「名剑的传闻」(5%)
```

### 稀有采集/矿点

```
定义: 特殊资源点, 固定位置但刷新随机
刷新: 1-7天不等
示例:
  「陨铁矿脉」: 刷新3天, 采集→「陨铁×1」(必)
  「龙血草」: 龙渊山剑池旁, 刷新7天, 采集中→概率获得「龙血草」
```
