# 区域与任务绑定设计

## 设计目标

> 对标《魔兽世界》经典旧世的区域设计哲学：**每张地图是一个自洽的小世界**——有专属的视觉风格、势力生态、任务群和危险带。玩家不是"在地图之间做任务"，而是"进入一个区域，就进入了一段地方史"。
>
> 战国版的三层结构：大地图上每个**国家**有自己的势力范围；国家内部每个**领主**有自己的封地；每个**区域**有自己的风格、势力和任务系统。三层互相嵌套，领土易主时，风格不变，但势力、任务、声望全部联动切换。

## 一、三层势力范围模型

```
大地图势力层级(嵌套):

┌─────────────────────────────────────────────┐
│ 第1层 国家势力范围 (国家层)                    │
│   七雄+周，动态边界，颜色见401/406             │
│   ┌─────────────────────────────────────┐   │
│   │ 第2层 领主封地 (领主层)                │   │
│   │   封君采邑：私兵/采邑任务/门客/叛乱     │   │
│   │   ┌─────────────────────────────┐   │   │
│   │   │ 第3层 本地势力 (阵营层)         │   │   │
│   │   │   学派/商帮/游侠/流寇/异族      │   │   │
│   │   │   声望驱动(见124/180)          │   │   │
│   │   └─────────────────────────────┘   │   │
│   └─────────────────────────────────────┘   │
└─────────────────────────────────────────────┘
```

### 1.1 国家势力范围（动态边界）

```
数据结构:
  势力范围 = {
    国家,
    城池列表: [咸阳, 栎阳, 雍城, ...],     ← 城池归属即领土归属(151)
    关隘列表: [函谷关, 武关, ...],
    边界折线: [(x,y)...],                 ← 相邻势力城池之间的分界
    领主封地: [商於, 陶, ...],            ← 嵌套第2层
  }

边界规则:
  1. 初始边界 = 以《六国年表》前350年前后格局为准(406原型图)
  2. 边界随战争变动(161 战争AI):
     城池易主 → 以该城为中心的辐射区(村庄/资源点)随之易主
     割地求和 → 边界线按割让城池重算
     灭国     → 全部领土并入战胜国
  3. 边界变动的连锁反应:
     地图颜色切换(401 势力层) → 领主封地重划(1.2)
     → 区域任务族切换(4.4) → 声望归属变更(180 国家声望)
```

### 1.2 领主封地（国家内层）

```
封君数据结构:
  封君 = {
    名号, 封地(1-3城池+辐射乡村),
    私兵上限 = 封地人口 × 征发系数,
    声望阵营ID(124 声望),          ← 独立的"领主声望"
    AI个性(161 效用框架简化版),     ← 内政/军事/对君主的忠诚
    任务链(采邑任务+门客任务),
    忠诚度(0-100) → 低于阈值可能叛乱/倒戈
  }

各国初始封君(示例, 随345年表动态变化):
  秦: 商君(商於) / 穰侯魏冉(陶邑) / 后期·文信侯吕不韦(雒阳)
  楚: 三闾贵族·屈景昭氏(郢都周边) / 春申君黄歇(江东·淮北)
  齐: 孟尝君田文(薛) / 安平君田单(安平)
  赵: 平原君赵胜(东武城) / 马服君赵奢(马服) / 后期·武安君李牧
  魏: 信陵君魏无忌(信陵) / 安陵君(安陵)
  燕: 昌国君乐毅(昌国)
  韩: 公仲氏(宜阳一带) / 公叔氏(新郑周边)
  周: 西周君 / 东周君(周室两小封君)

领主与玩家的关系:
  玩家可以成为封君(122 里程碑奖励"封地×1" / 124 爵位) →
  玩家的封地在大地图上以专属标记显示(自己的人生版图)
  玩家可与领主: 投效为门客(侠道M2.3) / 结盟 / 谋夺封地 / 平叛
  领主更替(死亡/罢免/叛乱) → 采邑任务刷新(4.4)
```

### 1.3 本地势力（声望阵营）

```
每个区域内活跃的非国家势力(声望驱动, 等级表见180):

  学派:   法家(关中)/稷下百家(山东)/纵横家(中原)/
          墨家(宋故地·魏) / 黄老(楚) → 隐道/王道任务源
  商帮:   齐盐商(山东)/秦蜀丝茶商(巴蜀)/吴越绸商 → 商道任务源
  游侠:   韩地剑客团(山西)/燕赵豪侠(河北) → 侠道任务源
  流寇:   山寨/水匪(各边境区, 治安<50刷新, 见404) → 赏金任务源
  异族:   匈奴/东胡(燕北)/义渠余部(关中北)/百越(吴越南)/巴人(巴蜀)
          → 高级区任务+战争事件源

规则:
  本地势力只在自己"势力影响区"内出没 → 区域风格的一部分
  玩家声望(124)决定: 可接任务等级/可学技能/是否被攻击(180 仇恨→崇拜)
  国家灭亡/领土易主 → 本地势力可能: 臣服新主/转入地下(流寇)/消失
```

## 三、任务-地图绑定机制

### 3.1 七条绑定规则

```
1. 归属绑定: 每个任务必须有 zone_id;
   接取地与目标地必须同区(跨区长线链除外——那是180法则3的史诗链)
2. 要素绑定: 任务目标必须引用地图要素——
   关隘(守关/攻关)、渡口(护送/漕运)、古墓(探索)、
   山寨(清剿)、城池(军政)、资源点(采集) (401/404)
3. 迷雾绑定: 区域未探索 → 不显示该区任务标记与NPC(401 战争迷雾);
   探索触发类任务(踏入隐藏区域)例外(180)
4. 声望绑定: 接取任务需该区域主势力声望达标(180 等级表);
   完成任务奖励对应势力声望(国家/领主/学派/本地)
5. 阶段绑定: 区域难度带对齐人生路线阶段(122 门槛);
   远低于/高于玩家阶段的任务显示为灰色(180 难度色)
6. 时间绑定: 任务有存在时间窗(锚定345 历史事件);
   时间窗过后 → 世界进入"历史已变"状态, 旧任务消失/转为余波任务
7. 动态绑定: 领土易主/领主更替 → 该区任务族整体切换(3.4)
```

### 3.2 任务枢纽分级

```
城池即任务枢纽(对应402 城池等级):

  Lv1 村庄: 1-2个教学任务(新手带)
  Lv2 乡镇: 2-4个日常/支线
  Lv3 县城: 区域支线 + 1条本地小故事线
  Lv4 郡城: 区域主线起点 + 学派/商帮/领主采邑任务
  Lv5 都城: 国家主线 + 人生路线里程碑(310) + 学派宗师 + 稀有任务

特殊枢纽(401 功能建筑 = 六条路线的任务据点):
  军营 → 霸道任务(军功/征兵/守关)
  朝堂 → 王道任务(献策/出使/会盟)
  酒馆 → 侠道任务(赏金/除恶/豪杰)
  市集 → 商道任务(商路/垄断/投资)
  工坊 → 匠道任务(定制/修复/革新)
  学宫 → 隐道任务(论道/著书/收徒)
  关隘 → 防御/攻关任务(所有路线, 需声望或官身)
  渡口 → 护送/漕运/缉私任务
```

### 3.3 区域主线链（每区一条地方史诗）

```
  关中: 「变法者」     商鞅车裂→新法之辩→客卿入秦
  中原: 「纵横天下」   苏秦合纵→张仪连横→五国伐秦
  河北: 「铁壁邯郸」   征兵→守城两年→窃符救赵→决战
  山东: 「火牛复国」   乐毅破齐→田单坚守→火牛阵→复国
  荆楚: 「郢都悲歌」   屈原放逐→白起南下→郢都陷落→楚人迁徙
  巴蜀: 「天府之路」   司马错灭蜀→修都江堰→粮仓北上
  山西: 「铁与弩」     宜阳冶铁→劲弩工坊→秦军压境
  燕北: 「北疆烽火」   筑长城→李牧守边→匈奴南侵
  吴越: 「越人之剑」   越国遗民→铸剑传说→楚人治水

规则: 区域主线在玩家首次进入区域(并满足阶段/声望)时开启;
      全程留在本区(含3-5个相邻子区), 结尾改变本区局部世界状态;
      错过时间窗(345)则换为"余波版"——世界不等人。
```

### 3.4 动态任务（领土与领主联动）

```
领土易主(161 战争AI驱动):
  例: 长平之战后上党归秦 →
     上党任务族从"赵版"(守土/求援/乡勇) 整体切换为"秦版"(移民/置县/清剿赵人)
     进行中的赵版任务 → 标记"使命已变"(交付或放弃)
     本地势力: 部分臣服(声望可继承打折) / 部分转为地下(新阵营)

领主更替(死亡/罢免/叛乱):
  新领主上任 → 采邑任务刷新 + 领主声望清零重刷
  领主叛乱 → 封地变"叛军领地"(红色标记) → 平叛任务(所有路线可接)
  领主倒戈敌国 → 封地随人走 → 边界重算(1.1)

历史时刻(345 事件窗口三连):
  事件前: 预警任务(各国军备/间谍/流言)
  事件中: 参战任务(军功/救援/护送)
  事件后: 余波任务(重建/复仇/反思)
  → 玩家出生越早, 经历的历史时刻越多(345 游戏时间标记)
```
